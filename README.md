# 모바일 청첩장 - 츄릭핑 버전

Next.js 15 + React 19 + Tailwind CSS 4 로 만든 모바일 청첩장 템플릿.

## 특징

- 모바일 퍼스트 반응형
- 12종 한글 웹폰트 라이브 토글
- 섹션: 메인 / 초대글 / D-day / 캘린더 / 갤러리 / 오시는 길 / 마음 전하실 곳 / 공유
- 구글 지도 임베드, 네이버/카카오맵 바로가기
- 계좌번호 원터치 복사, Web Share API

## 개발

```bash
npm install
npm run dev
```

`lib/data.ts` 에서 신랑신부 정보·날짜·식장·계좌·갤러리 이미지를 수정하면 됩니다.
